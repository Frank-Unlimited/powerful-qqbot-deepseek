每日额度

每一笔真实花费（模型、看图、联网、语音）按官方人民币价格计算，再按汇率折成 credits；北京时间 0 点重置。已经花掉的账不能改，只能充值和改上限。

个人

超出每日上限后从充值余额里扣，余额也用完才会停；管理员不受限制（照样记账）。个人额度在所有群和私聊里共用。

群

输入的排列顺序与缓存

DeepSeek 按"前缀"缓存：从请求开头起，和上一次完全相同的部分才算命中（价格约为未命中的 1/50）。越稳定的内容越要放前面，每轮都变的放最后。下面是当前的排列：

工具定义固定 · 几乎总命中
系统提示词　人格 + 平台规则固定 · 几乎总命中
历史消息　含以前的记忆头、工具结果只追加 · 命中
本轮输入　场景头 → 相关记忆 → 引用 → 正文 → 本轮工具结果每轮新增 · 不命中
  1. 每轮会变的信息（记忆、发送者、引用）放本轮消息，不进系统提示词——放进系统提示词会让整段前缀每轮失效。当前已是这样。
  2. 工具列表保持固定：功能开关不增删工具（关掉的工具被调用时直接报错），工具定义不变，缓存就不断。
  3. 改人格会在系统提示词处断一次缓存，之后重新稳定；尽量攒一批修改再保存。
  4. 上下文压缩会重写历史，压缩后第一轮大量不命中；窗口越大压缩越少，但每轮携带的历史越多。
  5. 可直接调的旋钮（「配置」页）：每轮注入记忆条数、旁听窗口、上下文窗口。
